RESUMING AFTER A CRASH:
  Just re-run the same command. The script reads download_state.json,
  skips completed files, and continues where it left off.

  $ python extract_yamuna_data.py
    ... (same prompts) ...
    [resume] skipping S2A_MSIL2A_20180615... (already downloaded)
    [resume] skipping S2B_MSIL2A_20190710... (already downloaded)
    ...
